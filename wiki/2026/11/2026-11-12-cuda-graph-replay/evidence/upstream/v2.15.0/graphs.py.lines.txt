658:         r"""End CUDA graph capture on the current stream.
659: 
660:         After ``capture_end``, ``replay`` may be called on this instance.
661: 
662:         Typically, you shouldn't call ``capture_end`` yourself.
663:         Use :class:`~torch.cuda.graph` or :func:`~torch.cuda.make_graphed_callables`,
664:         which call ``capture_end`` internally.
665:         """
666:         self.capture_end_pre()
667:         # Run the capture-end hooks while the template is live (both keep_graph modes). The
668:         # capture graph id is NOT read here: maybe_stamp_capture_root already stamped it at
669:         # capture_begin, and the template keeps that id for its whole life. Errors are user
670:         # bugs and propagate -- we deliberately don't wrap them in a finally that calls
671:         # capture_end_post(), since a failing finalize would mask the real error.
672:         if _global_capture_end_hooks:
673:             _run_global_hooks(_global_capture_end_hooks, self)
674:         for hook in list(self._capture_end_hooks.values()):
675:             hook(self)
676:         if not self._keep_graph:
677:             # Route keep_graph=False instantiation through Python so the remap
678:             # and post-instantiate hooks fire from instantiate().
