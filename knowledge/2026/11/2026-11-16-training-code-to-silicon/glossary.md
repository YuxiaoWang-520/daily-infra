# 术语表

按正文的阅读顺序查询。一个名称在不同厂商 SDK 中可能对应不同的组件边界，具体行为以该实现的接口约定为准。

| 术语 | 本文中的含义 | 与训练代码的联系 |
| --- | --- | --- |
| Host／Device | 主机 CPU 一侧／加速器一侧 | Python 组织计算，设备处理张量数值 |
| Tensor／Storage | 带 shape、stride、dtype 等元数据的张量／数值存储 | 多个视图可以引用同一 storage |
| Stride | 沿某一维前进一步跨过的元素数 | 影响地址计算和库是否能够直接接收输入 |
| Operator／算子 | 带明确输入输出与语义的框架操作 | `mm`、`relu`、`mean` 都属于操作 |
| Schema | 操作的参数、返回值及别名等接口约定 | 让分派、求导和变换理解操作的行为 |
| ATen | PyTorch 中承载大量 Tensor 操作及实现的核心部分 | Python 的 Tensor 操作通常进入相应 ATen 路径 |
| Dispatcher／Backend | 选择操作实现的机制／特定设备的实现集合 | 相同的 `mm` 连接到 CPU、CUDA 或扩展设备 |
| Autograd | 自动求导与反向依赖执行机制 | 从 loss 生成并执行梯度计算 |
| Graph／IR | 计算关系的图表示／中间表示 | 表达变换所需的操作、类型、布局或控制关系 |
| Eager | 随程序执行逐步发起操作的执行方式 | 本例逐行运行 Tensor 操作 |
| AOT／JIT | 提前编译／运行期间编译 | 库可提前构建，形状特化可在首次使用时生成 |
| Kernel | 一段可在设备启动执行的程序 | GEMM、激活或融合操作可以由 kernel 实现 |
| OS kernel | 操作系统内核 | 内核态驱动在此管理设备和特权资源 |
| GEMM | 通用矩阵乘法，常见形式为 `C=αAB+βC` | 前向和矩阵梯度中的主要计算 |
| Tile／Epilogue | 分块／主计算后对输出进行的处理 | 分块复用输入，epilogue 可加 bias 或激活 |
| Workspace | 算法在输入输出以外使用的临时工作存储 | 库的某些算法需要额外设备内存 |
| LLVM／MLIR | 可复用的编译基础设施／多层 IR 基础设施 | 为新设备构建变换与发码能力提供基础 |
| PTX／SASS／cubin | NVIDIA 的虚拟 ISA 表示／本机指令的常用称呼／设备二进制格式 | 描述 CUDA 设备代码从编译到加载的不同阶段 |
| ABI | 二进制层面的调用和数据布局约定 | 编译器、加载器与 launcher 要一致解释参数 |
| Runtime | 向应用提供设备执行与资源管理抽象的软件 | 管理 memory、stream、event 和 launch 等 |
| Context | 与设备相关的一组执行与资源状态 | 代码和资源操作需要处于适当 context |
| Stream／Event | 有序工作流／进度和依赖对象 | 组织异步计算、复制与等待 |
| Module／Function handle | 已加载代码模块／入口的句柄 | launcher 用句柄指定要启动的 kernel |
| User-mode／Kernel-mode driver | 用户态／内核态的驱动部分 | 分别承担进程内逻辑与 OS 特权资源等职责 |
| Firmware | 运行在设备控制处理器等位置的软件 | 可参与启动、命令处理、调度和设备管理 |
| Queue／Doorbell | 提交工作描述的队列／通知新工作到达的机制 | 将主机准备的任务交给设备控制端 |
| DMA | 由搬运硬件执行的数据传输 | 承担主机与设备或设备存储之间的搬运 |
| PCIe／BAR／MMIO | 设备互连／PCI 配置中的地址资源窗口／内存映射寄存器访问 | 支持设备枚举、资源映射与控制 |
| MMU／IOMMU | 地址转换及保护机制／面向设备访问的系统地址转换及隔离机制 | 约束进程或 DMA 能访问哪些内存 |
| ISA／Microarchitecture | 指令集架构／实现该语义的具体硬件组织 | 编译器面向 ISA，性能也受流水线和存储配置影响 |
| SIMD／SIMT | 单指令处理多数据／以多线程抽象组织相关并行执行 | 影响向量或线程程序的编写与调度 |
| SM／Warp／Block | CUDA 执行资源／常见线程调度组／线程块 | 用来说明 CUDA 的一种设备工作映射 |
| SRAM／HBM／DDR | 片上静态存储／高带宽存储技术／双倍数据率存储技术 | 架构在容量、带宽、成本与数据复用间做选择 |
| RTL／DV | 寄存器传输级描述／设计验证 | 定义并验证硬件的周期行为与功能 |
| PDK／IP | 工艺设计套件／可集成的设计模块 | 支撑目标工艺的芯片实现和接口集成 |
| Synthesis／Place & Route | 综合／布局布线 | 将 RTL 逐步落实为工艺单元与物理连接 |
| STA／DRC／LVS | 静态时序分析／设计规则检查／版图与电路一致性检查 | 验证物理实现的不同约束 |
| DFT／Bring-up | 可测性设计／首次系统启动与逐级调通 | 分别帮助制造测试与硅后研发定位 |
| Profiler／Correlation ID | 活动或性能采集工具／跨层事件关联标识 | 将一个主机操作连接到它提交的设备工作 |
| FLOP／Arithmetic intensity | 浮点运算计数／每字节数据流量对应的运算量 | 帮助评估计算与带宽需求 |

具体实现与验证边界见 [正文](README.md)，逐项来源见 [参考资料](references.md)。
