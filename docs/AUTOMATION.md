# 每日 Wiki 自动任务

## 时间与范围

- 时区：`Asia/Shanghai`（北京时间）。
- 时间：周一至周五每天 11:00 启动；周六、周日不运行。不额外判断节假日和调休。
- 频率：每次完成一个核心问题，同一日期最多一篇新文章。
- 工作目录：`/Users/wangyuxiao/Documents/ChatGPT/daily-infra`。
- 任务方式：定时回到当前聊天，读取仓库中的持久规范，继续学习路线与发布归档。
- Git 目标为公开仓库 [YuxiaoWang-520/daily-infra](https://github.com/YuxiaoWang-520/daily-infra) 的 `main` 分支，每篇通过审查后自动提交并推送。
- 每日工作指令：[DAILY_TASK.md](DAILY_TASK.md)。

11:00 是任务启动时间；研究、编码和审查完成后才发布。遇到来源获取或验证阻塞时保存草稿并报告原因。

## 运行条件

此任务需要读取和修改本地仓库。运行时应保持电脑开启、Codex 桌面应用运行、仓库路径可访问，并具备检索官方资料、拉取上游源码和推送 GitHub 所需的网络连接。本机 GitHub 认证须可用且有目标仓库的写入权限；凭据不写入仓库。相关运行要求见 [OpenAI 官方定时任务文档](https://learn.chatgpt.com/docs/automations)。

已完成的正文、资料笔记、证据、图源、练习、答案与审查记录保存在同一文章目录。任务完成报告提供阅读入口和验证摘要；未通过审查的内容保留在 `drafts/`。

## 审查后的自动同步

用户已授权两轮审查与必要验证通过后自动提交并推送，只包含本篇及必要的索引、导航更新。`playground/` 等无关改动保持原样。具体检查、提交范围和恢复规则见 [Git 同步流程](DAILY_TASK.md#git-同步流程)。

推送成功后报告 GitHub 提交链接。认证、网络、远端状态或提交范围异常时保留内容与已有提交，报告具体失败原因；下次先恢复同步，不重复生成文章或提交，不强制推送。

- 任务名称：工作日 AI Infra 知识 Wiki。
- 任务 ID：`ai-infra-wiki`。
- 类型：当前聊天的定时任务（heartbeat）。
- 状态：已启用，2026-10-22 创建；同日按用户要求改为 11:00。
- 同步授权：2026-10-22 按用户要求启用审查通过后的自动 Git 提交与推送。
- 2026-11-13 用户授权按公开仓库运行，已同步更新已保存的任务指令和仓库发布规则。

后续可在应用的定时任务页面调整时间或查看运行记录。若仓库迁移，需要同时更新已保存的任务指令和本文中的工作目录。
